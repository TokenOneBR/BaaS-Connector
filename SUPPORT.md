# Suporte

| Preciso de... | Va para |
|---|---|
| Entender como usar | [Documentacao](https://docs.baas-connector.dev) |
| Fazer uma pergunta | [GitHub Discussions](https://github.com/TokenOneBR/BaaS-Connector/discussions) |
| Reportar um bug | [Nova issue](https://github.com/TokenOneBR/BaaS-Connector/issues/new/choose) |
| Reportar vulnerabilidade | [SECURITY.md](SECURITY.md) — **nunca** em issue publica |
| Contribuir | [CONTRIBUTING.md](CONTRIBUTING.md) |
| Suporte comercial | contato@tokenone.com.br |

Antes de abrir issue, rode `pnpm up && pnpm e2e` e inclua a saida. Um bug
reproduzivel contra o Mock Bank e resolvido muito mais rapido do que um
descrito em prosa.

**Nunca cole em issue publica:** credencial de provedor, CPF/CNPJ real, chave
Pix real ou EndToEndId de transacao real.
